## 🧭 About

我专注把「真实浏览器自动化」做成可靠的 CLI 工具——不是模拟请求,而是用 **油猴脚本 + Bridge Server** 控制真实浏览器,在风控环境下也能稳定操作,并接入 **LLM** 让每个工具都具备智能决策能力。

**Bridge Framework** 是我的一套自动化架构,已在多个平台落地:

```
浏览器内(油猴脚本)                  ←→   本地 Bridge Server                 ←→   CLI / AI Agent
采集页面数据 / 执行真实操作                 JSON 双向通信、状态管理                  命令执行、LLM 决策
```
